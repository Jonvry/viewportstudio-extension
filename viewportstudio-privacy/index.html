ViewportStudio

Privacy Policy

Effective October 17, 2026

ViewportStudio helps you compare a website across responsive viewport sizes. The extension processes information locally in Chrome to load previews and, when synchronization is enabled, keep selected interactions aligned between them.

Information the extension processes

  • Page addresses and navigation: URLs for the page you choose and the pages opened in its workspace previews, so previews can load and follow navigation together. ViewportStudio does not create or send the developer a general browsing-history log.
  • Interactions: when synchronization is on, scroll positions, supported clicks, and values from eligible text fields, text areas, and selection controls are passed between the workspace previews. Password, file, hidden, checkbox, radio, and button inputs are excluded. Other eligible fields may contain personal or sensitive information, so avoid entering such information while synchronized previews are active.
  • Workspace settings: the current page and viewport, layout, zoom, and synchronization preferences are stored in Chrome extension storage on your device. Temporary per-tab embed settings use Chrome session storage.

How information is used and shared

The extension uses this information only to provide its responsive preview and interaction synchronization features. Workspace settings and synchronized interaction data are processed within Chrome and are not sent to a ViewportStudio developer-operated server. The extension does not use analytics or sell this information.

Previewed websites receive the page requests made by Chrome and may use their own cookies, storage, and page scripts. Any information you enter into a website may be handled by that website under its own privacy policy.

Embed compatibility

When enabled, embed compatibility adjusts selected framing request or response headers for iframe requests in the active workspace tab so some sites that block embedding can be previewed. This may change protections set by the website for framing. You can turn the feature off with the globe control in the workspace.

Storage and deletion

Workspace preferences remain in Chrome extension storage until you clear the extension's data or uninstall ViewportStudio. Temporary session settings are cleared when the browser session ends or the workspace policy is reset. The extension does not retain synchronized interaction values on a developer server.

Your controls

You choose which website to open in the workspace. You can turn interaction synchronization off in the workspace toolbar and can disable embed compatibility with its globe control.

Contact

For privacy questions, contact the developer using the email listed under “Developer” on the ViewportStudio Chrome Web Store listing.

This policy describes the ViewportStudio release currently prepared for the Chrome Web Store. It should be reviewed and updated if the extension's data handling changes.
